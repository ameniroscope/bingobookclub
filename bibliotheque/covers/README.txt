Covers can be either image files in this folder, or links.

LINKS (no files to manage):
  Open a book on the site, click the pen, and paste an image address in "Cover link".
  On Babelio, Booknode or StoryGraph: right-click the cover, then "Copy image address".
  Link covers need an internet connection to show.

FILES:
  Name each file after the book title in lowercase, with dashes instead of spaces and no accents:
    Jade City           -> jade-city.jpg
    L'Ombre du Vent     -> lombre-du-vent.jpg
    Fishbone Cinderella -> fishbone-cinderella.png
  Accepted: .jpg .jpeg .png .webp
  Or add one from the site: pen, then "Cover image file".

If both exist, a file chosen in the edit card replaces the link.
